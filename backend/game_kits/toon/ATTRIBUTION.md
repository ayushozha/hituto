# Toon character kit (Quaternius)

CC0 assets from Quaternius — [Toon Shooter Game Kit](https://quaternius.com/packs/toonshootergamekit.html).

Served at `/game-kits/toon/{Character_*.gltf}` for Hi Tuto game capsules (classic Three.js + GLTFLoader).

| File | Use |
|---|---|
| `Character_Soldier.gltf` | Default hero / guide |
| `Character_Hazmat.gltf` | Second station / alternate guide |
| `Character_Enemy.gltf` | Challenge / contrast station |

Animations include: Idle, Walk, Run, Wave, Yes, No, Punch, Jump, Death, …
